# Submission documents

| File | What it is |
|---|---|
| [`pitch-deck.html`](pitch-deck.html) | The pitch deck. 14 slides, each tagged with the judging pillar it serves. Also published live at [/attestable/deck.html](https://nailer.github.io/attestable/deck.html). |
| [`demo-run-sheet.html`](demo-run-sheet.html) | Script for the demo video — what to say, what to click, and the fallback if a cover misbehaves. |
| [`submission-answers.html`](submission-answers.html) | Copy-paste answers for the DoraHacks submission fields. |

These are plain HTML with no dependencies. Open any of them directly in a
browser, or print to PDF from there if a PDF is required.

Brand assets for the submission's logo field live in [`../brand`](../brand) —
use `attestable-mark-512.png`.
