# Submission documents

| File | What it is |
|---|---|
| [`Attestable-Pitch-Deck.pdf`](Attestable-Pitch-Deck.pdf) | **The deck as a PDF** — 14 slides, 16:9. |
| [`pitch-deck.html`](pitch-deck.html) | Same deck as a web page. 14 slides, each tagged with the judging pillar it serves. Also published live at [/attestable/deck.html](https://nailer.github.io/attestable/deck.html). |
| [`demo-script.md`](demo-script.md) | Script for the demo video — what to say and what to click, in order. |
| [`submission-answers.html`](submission-answers.html) | Copy-paste answers for the DoraHacks submission fields. |

These are plain HTML with no dependencies. Open any of them directly in a
browser, or print to PDF from there if a PDF is required.

Brand assets for the submission's logo field live in [`../brand`](../brand) —
use `attestable-mark-512.png`.
