# Attestable brand assets

The mark is a monogram **A**. The two legs are the two chains — evidence
originates on one, settlement happens on the other — and the brighter crossbar
is the proof that bridges them into a single letter.

It carries its own ground, so it reads the same on a light page, a dark page, a
slide, or a browser tab. Do not place it on a coloured background that fights
the navy, and do not recolour the crossbar: the colour split is what carries the
meaning.

| File | Use |
|---|---|
| `attestable-mark.svg` | Source. Scales to any size. |
| `attestable-mark-256.png` | Small avatars, favicons. |
| `attestable-mark-512.png` | **Submission logo.** Standard square upload. |

| `attestable-lockup-light.svg` / `-light-text.png` | Mark + wordmark for dark backgrounds. |
